PACMAN-42
=========

LAUNCH (LINUX / MACOS)
  Extract the complete ZIP archive first.
  Open a terminal in the extracted Pacman-42 folder, then run:

    ./Pacman-42

  The executable uses built-in default settings when no argument is given.
  Keep the _internal/ directory alongside the executable.
  Use the archive built for your system: Linux or macOS.
  A Linux executable cannot run directly on macOS, or vice versa.

CONFIGURATION
  Without an argument, the game uses its built-in default settings.
  To use custom settings, provide a configuration file:

    ./Pacman-42 config.json

  Place your configuration beside the executable or use an absolute path.
  The repository's config.json can be used as an example.

CONTROLS
  Arrow keys / W A S D   Move Pac-Man
  Up / Down              Navigate the main menu
  Enter                  Confirm a menu selection
  Escape                 Pause during a game
  Enter (while paused)   Resume
  Escape (while paused)  Return to the main menu
  Q                      Quit during gameplay or from the pause screen
  Backspace              Delete a character when entering a name

CHEATS
  C    Show or hide the cheat menu
  N    Toggle noclip (move through walls)
  I    Toggle invisibility to normal ghosts
  L    Request the next level

HIGHSCORES
  In the packaged game, highscores are stored beside the executable:

    Pacman-42/
      Pacman-42
      scores.json

  The filename comes from highscore_filename (scores.json by default).
  Only the filename is used; scores stay in the executable's directory.
  A missing file is created automatically with an empty ranking, without
  displaying a warning. Loading and saving always use the same file,
  regardless of the directory from which the executable is launched.
